[Analog-765] 当外设电源域关闭时，输出调压器无法正常供电
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. only:: esp32p4

   .. tags::

      v3.0

描述
^^^^

当外设电源域被关闭时，输出调压器无法正常供电。

变通方法
^^^^^^^^

如果希望使用输出调压器为外部 PCB 组件供电，请勿在 Light-sleep 模式下关闭外设电源域。

解决方案
^^^^^^^^

.. only:: esp32p4

   已在芯片版本 :bdg-success:`v3.1` 中修复。
