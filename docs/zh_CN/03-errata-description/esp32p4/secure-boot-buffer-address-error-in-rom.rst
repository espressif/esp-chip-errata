[ROM-764] ROM 中安全启动缓冲区地址错误导致验证失败
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. only:: esp32p4

   .. tags::

      v3.0

描述
^^^^

在 ROM 中，安全启动阶段缓冲区的起始地址配置错误。该地址指向了 L2 缓存数据存储器 (0x4FF0_0000)，该区域属于 L2 缓存的一部分，CPU 无法写入。

由于此错误配置，存储在安全启动缓冲区中的数据可能会丢失，可能导致安全启动过程中的哈希计算失败或签名验证失败。

变通方法
^^^^^^^^

请勿启用安全启动功能。

解决方案
^^^^^^^^

.. only:: esp32p4

   已在芯片版本 :bdg-success:`v3.1` 中修复。
