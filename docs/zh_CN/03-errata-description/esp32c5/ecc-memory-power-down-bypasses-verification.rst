[ECC-833] 强制关闭 ECC 存储器电源会绕过 ECDSA_DS 签名验证
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. only:: esp32c5

   .. tags::

      v1.0, v1.2

描述
^^^^

在 {IDF_TARGET_NAME} 芯片中，若通过系统寄存器强制关闭 ECC 存储器电源，ECDSA_DS 会将任何提交的签名均判定为有效。

变通方法
^^^^^^^^

将签名方案从 ECDSA_DS 切换为 RSA_DS。

解决方案
^^^^^^^^

预计将在 :bdg-warning:`下个芯片版本` 中修复。
