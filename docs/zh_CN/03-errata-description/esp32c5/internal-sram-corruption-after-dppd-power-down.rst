[SRAM-436] 数字外设电源域掉电导致内部 SRAM 内容可能被改写
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. only:: esp32c5

   .. tags::

      v1.0

描述
^^^^

在部分 {IDF_TARGET_NAME} v1.0 芯片中，当启用数字外设电源域掉电功能时，可能出现内部 SRAM 的部分内容被改写的情况，从而导致 CPU_LOCKUP 复位或系统挂死。

变通方法
^^^^^^^^

在 ESP-IDF v5.5 及以上版本中，{IDF_TARGET_NAME} v1.0 已禁用数字外设电源域掉电功能。

解决方案
^^^^^^^^

已在芯片版本 :bdg-success:`v1.2` 中从硬件层面修复。
