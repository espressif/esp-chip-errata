[FLASH-938] CPU 频率为 240 MHz 时 flash 手动加密失败
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. only:: esp32c5

   .. tags::

      v1.0, v1.2

描述
^^^^

在 {IDF_TARGET_NAME} 芯片中，由于内部功耗波动，在 CPU 频率为 240 MHz 时执行 flash 手动加密可能会失败。

变通方法
^^^^^^^^

在执行 flash 手动加密时，将 CPU 频率降低至 160 MHz 或更低。

解决方案
^^^^^^^^

:bdg-warning:`暂无` 修复计划。
