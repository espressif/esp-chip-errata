[SPI-855] 1.8 V VDD_SPI 条件下无法从 flash 启动
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. only:: esp32s31

   .. tags::

      v0.0

描述
^^^^

EXT_LDO_DREF 默认值对应的电压不是 1.8 V，芯片无法在 1.8 V VDD_SPI 条件下从 flash 启动。

变通方法
^^^^^^^^

使用 3.3 V VDD_SPI 从 flash 启动。

解决方案
^^^^^^^^

预计将在 :bdg-warning:`下个芯片版本` 中修复。
