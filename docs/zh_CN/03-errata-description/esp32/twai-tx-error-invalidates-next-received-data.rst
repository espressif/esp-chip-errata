[TWAI-880] 发送数据帧时发生总线错误可能导致下一次接收到的数据字节无效
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. only:: esp32

   .. tags::

      v0.0, v1.0, v1.1, v3.0, v3.1

描述
^^^^

当 TWAI 控制器发送数据帧时，如果在数据段或 CRC 字段发生总线错误，下一次接收到的数据可能发生字节移位。该帧的标识符和数据长度仍可能正确，且控制器不会对该接收帧报告错误。因此，下一次接收的数据帧应视为无效。

控制器在发送和接收时共用一个字节计数器来监测总线活动。发送期间如果在数据段发生总线错误，且该帧在 CRC 字段之前结束（计数器通常在 CRC 字段被清零），计数器会停留在错误状态，从而使下一次接收帧的数据字节发生移位。

变通方法
^^^^^^^^

置位 INTERRUPT_BUS_ERR_INT_ENA。接收到总线错误中断时，读取 ERROR_CODE_CAPTURE_REG，以检测发送期间数据段或 CRC 字段中的总线错误。如果符合该条件，复位 TWAI 控制器（需要保存并恢复当前寄存器的数值）。
