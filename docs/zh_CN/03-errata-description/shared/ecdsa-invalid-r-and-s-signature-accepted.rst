[ECDSA_DS-836] ECDSA_DS 异常接受无效 ``r`` 和 ``s`` 值签名
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. only:: esp32h2

   .. tags::

      v1.2

.. only:: esp32p4

   .. tags::

      v3.0, v3.1, v3.2

.. only:: esp32s31

   .. tags::

      v0.0

描述
^^^^

当向 ECDSA_DS 外设提交带有无效 ``r`` 和 ``s`` 值的签名 ``{r = 0 或 n，s = 0 或 n}`` 进行任意消息和公钥验证时，该外设会错误地将此签名报告为 "valid"。

变通方法
^^^^^^^^

使用 RSA_DS 安全启动替代 ECDSA_DS 安全启动。

解决方案
^^^^^^^^

.. only:: esp32h2 or esp32p4

   :bdg-warning:`暂无` 修复计划。

.. only:: esp32s31

   预计将在 :bdg-warning:`下个芯片版本` 中修复。
