[ECDSA_DS-837] ECDSA_DS 异常接受无效 ``s`` 值签名
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. only:: esp32h2

   .. tags::

      v0.0, v0.1

.. only:: esp32p4

   .. tags::

      v0.0, v1.0, v1.3

描述
^^^^

当向 ECDSA_DS 外设提交带有无效 ``s`` 值的签名 ``{r = (Qa + G).x，s = 0 或 n}`` 进行任意消息和公钥验证时，该外设会错误地将此签名报告为 "valid"。

变通方法
^^^^^^^^

使用 RSA_DS 安全启动替代 ECDSA_DS 安全启动。

解决方案
^^^^^^^^

:bdg-warning:`暂无` 修复计划。
